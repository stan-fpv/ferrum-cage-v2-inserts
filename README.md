# Ferrum Cage V2 – camera inserts (STL)

Swappable TPU camera inserts for the **Luceed Ferrum Cage V2**.
Easiest way to grab the right pair: the insert picker at **[luceedfpv.com](https://luceedfpv.com/pages/cage-v2)** – pick your cam, see it in 3D, download.

This repo contains **only the inserts**. The cage itself is sold at luceedfpv.com.

## Print

- TPU, one `_L` and one `_R` per camera.
- Screws: M2×8 – 2 per side (1 per side for single-hole micro / nano cams).
- Files are already in the cage's coordinate system – no need to move them in the slicer, just lay them flat.

| `Micro_19mm_1otwor` | 19 mm micro analog / HDZero Micro / RunCam Link… | 19 mm | 1 |
| `Nano_14mm_1otwor` | 14 mm nano cams | 14 mm | 1 |

File names: `fixNN` = fixed NN° tilt, `varA_B` = variable tilt A…B° on arcs (or on the single screw), `_slot` = slotted holes for fore/aft adjustment.
